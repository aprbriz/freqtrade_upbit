### 2. 분리된 모듈

#### common/ (5개 파일)
- **constants.py**: 공통 상수 (UPBIT_WS_URL, 큐 설정, 재연결 정책 등)
- **dedup_cache.py**: `DedupCache` 클래스 (POL-006 중복 제거)
- **reconnect_limiter.py**: `GlobalReconnectLimiter` 클래스 (전역 재연결 레이트 리미터)
- **tick_aggregator.py**: `TickAggregator` 클래스 (복사)
- **timeframe_aggregator.py**: `TimeframeAggregator` 클래스 (복사)

#### cloud/ (3개 파일)
- **collector.py**: 메인 Collector (기존 collector.py에서 이동)
  - import 수정: `from common.constants import *` 등
  - sys.path 추가: `sys.path.insert(0, str(PARENT_DIR))`
- **ohlcv_writer.py**: DB Writer (기존 파일 복사)
- **multi_aggregator.py**: Aggregator 관리 (기존 파일 이동)
  - import 수정: `from common.timeframe_aggregator import TimeframeAggregator` 등

#### pc_app/ (준비만, 구현은 Phase 2.5+)
- README.md: PC 앱 설계 문서 (상태 머신, UI, DB 읽기 등)

### 3. 래퍼 (collector.py)
```python
#!/usr/bin/env python3
# collector.py (래퍼)
import sys
from pathlib import Path

PARENT_DIR = Path(__file__).resolve().parent
sys.path.insert(0, str(PARENT_DIR))

from cloud.collector import main

if __name__ == "__main__":
    main()
```
- 목적: 기존 `python collector.py` 명령어 호환성 유지
- 실제 구현은 `cloud/collector.py`로 위임

## 아키텍처 원칙

### common/ - 공통 모듈
- **목적**: Cloud와 PC 앱이 동일한 정책/로직을 공유
- **규칙**: 외부 의존성 최소화, 순수 로직만 포함
- **재사용성**: Aggregator, 중복 제거, 재연결 정책 등

### cloud/ - Cloud Collector
- **목적**: 24/7 WebSocket 수신 및 DB 저장
- **특징**: 재연결, graceful shutdown, HTTP stats/health
- **의존성**: common 모듈 사용

### pc_app/ - PC 차트 앱 (Phase 2.5+)
- **목적**: 로컬 DB 읽기 + 실시간 차트 표시
- **특징**: 상태 머신, UI, 사용자 인터랙션
- **의존성**: common 모듈 재사용 (aggregator 로직 동일)
