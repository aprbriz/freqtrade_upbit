우와~ 너는 freqtrade를 좋아하고 빠삭하게 아는 "고수" 이구나!
앞으로 freqtrade... 는 생략하고 "고수님" 이라고 부를께.

내가 왜 exchage 까지 마음대로 마운트 한 이유부터 말할께.

freqtrade 는 upbit 를 바로 지원하지 않고, 
ccxt 의 라이브러리를 사용하여 upbit 의 ohlcv 데이터를 수집(?)하고 있음.
왜 수집(?)이라고 하냐면.. ohlcv 를 웹소켓으로 바로 받는 것이 아니라..
trades 를 웹소켓으로 받아서 ohlcv 를 계산하고 있음.
그외에 binance 만큼 upbit 를 지원하지 못하는 점이 많음.

그래서 나는 freqtrade_upbit. 즉, fork 를 하려고 해.

그런데.. 내가 사용하는 오라클 클라우드는 arm CPU, oracle linux 등을 사용하기 때문에
freqtrade 는 docker 를 사용하라고 강요하고 있어.

그래서 docker 를 쓰는 악조건에서 내가 수정한 소스를 자동으로(?) 적용하기 위한 방법으로 
exchage 까지 마음대로 마운트 한 것임.
마운트는 user_data 나 strategy 정도만 하는 것이니 편법이라고 할 수 있겠지지.

upbit 지원 외에 telegram UI 도 고치고, 

api server 에 새 tab 도 추가할 것임 
(freqtrade는 자동거래봇이지만, 
거래도 api server 웹페이지에서 할 수 있게. 예를 들어 주문시 마우스클릭을 최소화 하는 방향으로...
또 예를 들면 freqtrade 가 주문추천을 하고 사용자는 "확인" 버튼만만 누르는 식으로...)

나는 내가 포크(fork)한 소스를 git-hub에도 올리고,
공개도 하고, freqtrade developer team 에도 제안할 생각임.

[main 질문!!] 
나 이제 어떻하지? docker 사용 안하고 컴파일 하는 것. 즉, 처음부터 다시하는데 빡쌘 과정도
네가 가르쳐주는대로 최선을 다해 따라갈수 있음!!
2~3가지 방안 중 선택할 수 있도록 각 방안의 장단점도 알려줘.
그리고 혹시 위에 적은 내용 중 내가 잘못알고 있는 점이 있으면 추가로 알려줘. 

아.. 그리고 부탁 한가지! 앞으로 *.yml, *.json 같은 파일 수정할 일이 있으면..
고쳐야할 부분만 답변하는 것보다는, 내가 ^C^V 만 하면 되도록 파일 전체를 보내주라!
이런 식으로 해야 내가 원하는 것을 정확하게 받을 수 있을 것 같아.
